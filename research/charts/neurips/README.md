# Paper-specific figure renderings and hand-written tables

**This folder holds only what does not exist in `../`.** Seven files here used to be byte-identical
copies of the numbered charts one level up, under paper-figure aliases that nothing referenced;
they were deleted and `build_charts.sh` no longer recreates them. Every numbered chart lives at
exactly one path: `charts/`.

## The three PNGs

`fig1_pipeline.png`, `fig2_severity_x_action.png` and `figA2_access_type.png` are **different
renderings**, not copies — laid out for a two-column paper rather than for the dashboard. They are
drawn straight into this folder by `scripts/nfig1_pipeline.py`, `nfig2_matrix.py` and
`nfigA_access.py`, and are regenerated by `bash scripts/build_charts.sh` like everything else.
Their dashboard counterparts are `20_accountability_pipeline_funnel.png`,
`21_severity_x_action_heatmap.png` and `03_findings_per_access_type.png`.

## The two .tex tables

Hand-written and **not** regenerated by the build:

- `table1_examples.tex` — three worked C1 / Tier A examples, severity held constant so the only
  quantity varying across rows is the company response. Every row is a real finding
  (`METR-2026-06-ALI1`, `UKAISI-2026-04-JAI1`, `UKAISI-2026-04-CYB1`); if any is removed from the
  corpus this table must be rewritten by hand.
- `table2_institutions.tex` — the design-feature comparison against FDA, NRC, NTSB, PCAOB, ONR,
  FCA and CAA. It contains no corpus statistics, so a corpus change never invalidates it and its
  file date is expected to lag the workbook.

Current corpus: **1,146 findings · 457 reports · 46 institutions · Tier A 233 · Tier A C1 190 ·
headline 152/190 = 80.0%**. `scripts/verify_charts.py` must print PASS before submission.
