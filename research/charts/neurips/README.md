# ICML submission figure set

Generated, not edited. `bash scripts/build_charts.sh` from the project root refreshes every
`.png` here: three are drawn directly by `nfig1_pipeline.py`, `nfig2_matrix.py` and
`nfigA_access.py`, and seven are copied from their numbered originals in `../` by the mapping at
the foot of that script. Editing a file here is always wrong — change the generator and rebuild.

The two `.tex` tables are hand-written and are **not** regenerated by the build:

- `table1_examples.tex` — three worked C1 / Tier A examples, severity held constant so the only
  quantity varying across rows is the company response. Every row is a real finding
  (`METR-2026-06-ALI1`, `UKAISI-2026-04-JAI1`, `UKAISI-2026-04-CYB1`); if any is removed from the
  corpus this table must be rewritten by hand.
- `table2_institutions.tex` — the design-feature comparison against FDA, NRC, NTSB, PCAOB, ONR,
  FCA and CAA. It contains no corpus statistics, so a corpus change never invalidates it. Its
  file date is therefore expected to lag the workbook.

Current corpus: **1,147 findings · 458 reports · 46 institutions · Tier A 233 · Tier A C1 190 ·
headline 152/190 = 80.0%**. `scripts/verify_charts.py` recomputes every plotted quantity from the
workbook and must print PASS before submission.
