by mis-parsing one joint Institution string, and 716 from zero-yield Network members.

ledger so the exclusion counts remain reconstructable, which is why "publications screened" is 6,684 while
the active-corpus denominator is smaller.

## Rebuild from scratch

```
cd scripts
./build_charts.sh                      # every figure -> ../charts
python3 verify_charts.py               # independent recomputation of every figure
python3 ../dataset/AISIEVAL_validate.py
```
