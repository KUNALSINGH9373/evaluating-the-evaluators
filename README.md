# Evaluating the Evaluators

Interactive dashboard over a source-verified dataset of AI safety–evaluation findings:
when government AI safety institutes and third-party evaluators flag a problem, do the
named companies respond?

**Live site → https://kunalsingh9373.github.io/evaluating-the-evaluators/**

- `index.html`, `app.js`, `tags3d.js` — the dashboard
- `data.js`, `dataset.csv` — the finding-level dataset
- `charts/` — summary figures
- `codebook.md` — column definitions

The dataset is provided for transparency and public reference.
